Análisis de Precios: Bitcoin vs Ether
​📌 Descripción del Proyecto
​Este proyecto se enfoca en la limpieza y análisis exploratorio de datos (EDA) de los precios históricos de Bitcoin y Ethereum. El objetivo principal fue transformar datos crudos en un dataset estructurado listo para análisis estadístico y futuro modelado con Machine Learning.
​🛠️ Tecnologías Utilizadas
• ​Python: Lenguaje principal.
• ​Pandas: Para manipulación y limpieza de datos.
• ​Seaborn & Matplotlib: Para visualización avanzada (Histogramas, ECDF, Rug Plots).
• ​Jupyter Notebooks: Entorno de desarrollo.
​🧹 Proceso de Limpieza
• ​Tratamiento de valores nulos y duplicados.
• ​Conversión de formatos de fecha y limpieza de símbolos de moneda.
• ​Exportación de datos limpios a formatos .csv y .xlsx.
​📊 Hallazgos Clave
• ​Se analizó la distribución de precios mediante funciones de densidad (KDE) y distribución acumulada (ECDF).
• ​Identificación de cuantiles clave para entender la volatilidad de ambos activos

# Laboratorios

Esta carpeta reúne los laboratorios prácticos que he desarrollado como parte de mi proceso de formación en análisis de datos con Python.

Cada laboratorio aborda un conjunto de técnicas y herramientas aplicadas al análisis de datos, permitiéndome fortalecer habilidades mediante la resolución de problemas y el trabajo con conjuntos de datos reales.

## Contenido

Los laboratorios incluyen actividades relacionadas con:

- Análisis exploratorio de datos (EDA)
- Limpieza y preparación de datos
- Manipulación de datos con Pandas
- Estadística descriptiva
- Visualización de datos
- Interpretación y comunicación de resultados

## Herramientas utilizadas

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib

## Objetivo

Documentar mi progreso y consolidar conocimientos mediante la práctica constante, aplicando buenas prácticas en el análisis de datos y el uso del ecosistema de Python.

> Estos laboratorios forman parte de mi proceso de aprendizaje y fueron realizados siguiendo las actividades propuestas en el programa **Google Advanced Data Analytics Professional Certificate**, complementadas con mi propia exploración y práctica.
